# 🔘 ボタンルーム脱出(最大5人・オンライン3D)

壁一面に32個のボタン。**出口ボタンは1つだけ**。先に押した人が脱出(勝ち)。制限時間5分。

## 起動
```
npm install
npm start
```
ブラウザで http://localhost:3000 を開く。
友達と遊ぶ場合は同じネットワークなら `http://<あなたのIP>:3000`、
インターネット越しなら Render / Fly.io 等にデプロイするか ngrok などで公開してください。

## 操作
WASD 移動 / Shift ダッシュ / マウス 視点 / 左クリック ボタンを押す

## ルール
- ボタンは一度押すと全員に結果が公開され、二度と押せない
- 💡ヒント(6個): 出口についての本当の情報が全員に配られる
- ❄凍結(6個): 押した人は5秒動けない
- 🌑暗闇(4個): 押した人は6秒画面が真っ暗
- 🌀ワープ(4個): 押した人がランダムな場所へ飛ぶ
- ・ハズレ(11個): 何も起きない
- 🚪出口(1個): 押した人の勝ち
