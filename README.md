# 🔘 ボタンルーム脱出(最大5人・オンライン3D)

壁一面にボタン(ロビーで 32 / 72 / 128 / 200個 から選択)。**出口ボタンは1つだけ**。先に押した人が脱出(勝ち)。制限時間5分。

## 起動
```
npm install
npm start
```
ブラウザで http://localhost:3000 を開く。
友達と遊ぶ場合は同じネットワークなら `http://<あなたのIP>:3000`、
インターネット越しなら Render / Fly.io 等にデプロイするか ngrok などで公開してください。

## 操作
WASD 移動 / Shift ダッシュ / Space ジャンプ(空中でもう一度押すと連続ジャンプ。高い段のボタンへは跳び上がって届く) / マウス 視点 / 左クリック ボタンを押す

## ルール
- ボタン数(32 / 72 / 128 / 200)はホストがロビーで選ぶ。多いほど部屋も広くなる
- 押したボタンは全員に結果が公開され、二度と押せない。先に🚪出口を押した人の勝ち
- 基本のボタン: 💡ヒント / ❄凍結 / 🌑暗闇 / 🌀ワープ / ・ハズレ / 🚪出口
- さらに下記の **30種類のイベント** がランダムに混ざる(各効果の秒数は server.js の EVENTS で変更可)

### 追加イベント30種
| 分類 | イベント |
|---|---|
| 押した人に起こる(良い) | ⚡ダッシュ / 🐭縮小(低い視点) / 🦒巨大化(高い視点で見渡せる) / 🛡バリア(次の悪い効果を1回無効化) |
| 押した人に起こる(悪い) | 🐌鈍足 / 🙃操作反転 / 👁超広角 / 🔭望遠 / 📳地震 / 🌫濃霧 / 🌈虹色 / 🎞色反転 / 😵ぼやけ / 📸フラッシュ / 💫強制回転 |
| 全員に起こる | 🔌全員停電 / 🥶全員凍結 / 🔄位置シャッフル / 💥全員ランダム散開 / ⏳残り時間+30秒 / ⌛残り時間-30秒 |
| 他人に起こる | 🕶押した人以外が暗闇 / 🧲全員を押した人の周りに集合 / 🎯ランダムな1人を6秒凍結 |
| 情報系 | 🔮ヒント2つ / 🤡ピエロのヒント(本当かウソか不明) / 🌡温度計(出口までの距離・自分だけ) / 🧭羅針盤(出口の方角・自分だけ) / 🧹お掃除ロボ(ハズレ3個を除去) / 🎰ギャンブル(50%でヒント2つ、50%で8秒凍結) |

## 動かないとき
- `npm install` を実行したか(ws が必要)
- `file://` で index.html を直接開かず、必ず http://localhost:3000 から開く
- 画面が古い場合は Ctrl+Shift+R(強制再読み込み)。サーバーも再起動する
- 画面下に赤い帯でエラーが出た場合は、その文面を教えてください
